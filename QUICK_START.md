# 🎵 GhostBus - Premium Ghost Production Marketplace

**Full-stack marketplace with Express/Node backend + React frontend**

---

## 🚀 Quick Start (2 Steps)

### Step 1: Start Backend
```bash
cd Backend
npm run dev
```
✅ Backend running on **http://localhost:3000**

### Step 2: Start Frontend (New Terminal)
```bash
cd Frontend
npm run dev
```
✅ Frontend running on **http://localhost:5173**

## 🔧 Tech Stack

### Backend
- Express.js + Node.js
- PostgreSQL (Supabase)
- Prisma ORM
- JWT Authentication
- bcrypt Password Hashing

### Frontend
- React 19
- TanStack Router
- Axios
- Tailwind CSS v4
- Framer Motion
